Maquettes

Maquettes HTML statiques, mobile d'abord. À ouvrir sur un téléphone ou en largeur réduite.

L'écran d'entrée : une action principale, le pouce droit.

2 · Carte produit : les quatre niveaux

Le résultat : une ligne par source, avec date et validité ; le seuil de l'utilisateur.

2 bis · Carte produit : produit non cité sur les listes

Variante : aucun logo, aucune liste ; l'action principale devient « Scanner les ingrédients ».

2 ter · Carte produit : liste périmée

Variante : la source citée est expirée, en ambre, jamais en vert.
